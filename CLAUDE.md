## Component Development Rules

When improving, creating, or modifying any UI component:

1. **Always use the Magic MCP** (`/ui`) to generate or reference modern component patterns from the 21st.dev library before writing component code
2. **Always use the Stitch MCP** to extract design context (colours, typography, spacing) and ensure consistency with the project's design system
3. **Always use Nano Banana 2** to generate any visual assets, placeholder images, or icons needed
4. **Always apply the UI UX Pro Max skill** for layout, accessibility, interaction patterns, and visual polish
5. Combine the outputs — Magic MCP for component structure, Stitch for design tokens, Nano Banana for assets, UI UX Pro Max for best practices

Never improve a component using only your built-in knowledge. Always consult the available MCP tools and skills first.
